# Kanban - Board

## About the Project

I built this minimalist Kanban board because I found existing solutions to be visually cluttered and bloated with unnecessary features. My goal was to create a clean, black-and-white interface that retains only the essential functionality for task management.

Primarily, this project serves as a hands-on learning environment to reinforce my knowledge of **React** and **TypeScript**, while deeply exploring state management using **Zustand** (Client State) and **TanStack Query** (Server State), alongside advanced CSS Modules.

### Current Features (MVP)

- **Task Management:** Create tasks and search for them by title.
- **Column Management:** Use default columns (To Do, In Progress, Done) or create custom ones.
- **Drag and Drop:** Seamlessly move tasks between columns.

### Roadmap

Most of the upcoming features will be implemented to further my technical practice:
